# CHÉRIE Office

Website office.cherie.io.vn — tủ đồ đi làm theo tháng ở Đà Nẵng.

- `index.html`: trang web (một trang, điều hướng bằng #).
- `office-data.js`: danh sách món đang hiện trên web.
- `CNAME`: tên miền office.cherie.io.vn.

Dữ liệu và phân quyền của Office tách riêng với cherie.io.vn (Sheet "CHÉRIE Office · Quản lý").
